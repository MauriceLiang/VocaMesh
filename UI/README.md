# VocaMesh · UX/UI 设计交付（v1.2）

**VocaMesh — A Vocafect Product** · 本地优先、跨平台、多 Agent 调用与协作的桌面平台。
本轮为**设计交付**（信息架构 → 低保真 → 高保真 → 设计系统 → 可交互 Mock → 验收），不含正式运行时实现。

---

## 1. 快速开始（60 秒）

1. **看设计**：打开画布 `UI/VocaMesh.pen`（顶层框架按 `00 → 04` 顺序排列，S01–S16 在下半区）。
2. **点原型**：双击打开 `UI/prototype/index.html`（零依赖、无需安装、无需服务器；建议窗口 1280×800 或更宽）。
3. **看汇总**：`UI/qa/evidence/export.pdf`（S01–S16 十六页合集）。
4. **读结论**：`UI/qa/REVIEW_NOTES.md`（评审用）与 `UI/qa/UX_QA_REPORT.md`（T01–T24 结果）。

> 原型内所有数据为**虚构演示数据**；不调用真实 CLI、不读写文件、不发送网络请求、不收集任何凭据。
> 原型“重置演示”位于：设置 → 关于 → 重置演示数据。

## 4. 原型能做什么（摘要）

> **全部控件可交互**：14 个页面 + 15 个弹窗内的每一个交互元素都已绑定真实行为（脚本校验 0 个死按钮、200+ 次点击 0 异常）。

- 11 个可点击入口（工作台 / 全部任务 / 待审批 / 历史记录 / Agent 角色 / 本地工具 / Agent 团队 / 工作空间 / 通知 / 设置 / 帮助与反馈）+ 首次启动页 + 状态合集页。
- 创建任务：模板弹窗、工作空间菜单、三种执行方式、附件、授权边界；创建后 `排队中 → 执行中`。
- 任务详情：执行流程、主管对话、审批卡、暂停 / 停止 / 继续 / 重试 / 跳过生成部分成果；任务菜单（复制链接 / 导出摘要 / 归档）。
- 检查器：活动 / 日志 / 成果 / 信息；日志搜索、级别筛选、复制、加载更早、文件预览、时间线定位。
- 定向指令：`排队 → 已送达 → 等待安全投递点 → 已应用` 四段状态 + 主管同步提示。
- 筛选与菜单：任务表四维筛选、历史记录三维筛选、行菜单、成员菜单、附件菜单、日志保留菜单。
- 真实本机行为：复制到剪贴板（含回退）、导出 Run／任务／部分成果文件（Blob 下载）。
- **Agent 关系图（可操作）**：拖动平移、滚轮/按钮缩放、拖动节点排布、节点 `+` 添加下属、`⋯` 编辑 / 加下属 / 改上级 / 设为主管 / 移除；环检测阻断；画布内「+ 添加 Agent」直接建档并挂到选中节点下。
- 主题（跟随系统 / 亮 / 暗）、密度（舒适 / 紧凑）、灰度预览、macOS / Windows 标题栏预览。
- 命令面板 `⌘K` + `↑↓` + `Enter`、`Esc` 逐层关闭、`Enter` 发送消息、侧栏折叠与返回。

详细清单与已知限制见 `prototype/README.md`。

### 4.1 交付结构说明（与建议目录的差异）

- **wireframes / screens 不另建重复目录**：低保真与高保真均以画布框架形式交付（`05 · 低保真线框`、`S01–S16`），并以 1:1 PNG 导出到 `qa/evidence/`（含暗色与 1024 变体）、汇总为 `export.pdf`。这样可编辑源只有一份，避免图片与源文件不一致。
- **无 `assets/`**：本轮未使用任何外部素材；图标为画布内置图标库与原型内联 SVG，演示图像均为几何占位，不存在第三方素材许可问题。
- **原型零依赖**：无 `package.json`、无锁文件、无构建缓存；所有资源均在 `prototype/` 内相对引用，不存在 `../` 跨目录引用。

## 5. 关键设计约束（评审请重点核对）

0. **布局网格统一**：页面内边距 26 · 列表列 320 · 右栏 340 · 分区导航 200 · 列间距 12 · 列表卡片 12 / 详情面板 16 / 导航容器 8；全部页面标题左边缘对齐在 266px，两列等高，控件高 32。详见 `design-system/components.md` §1.1。

1. **任务优先**：默认页是工作台，输入区是第一焦点；组织架构不占首屏。
2. **单层分组导航**：11 个入口、文字优先、一次点击到达；侧栏**始终展开 240px、不提供折叠**；设置/帮助固定底部。
3. **黑白灰 + 三语义色**：选中=中性底+轻阴影+字重；Focus=2px 独立轮廓；绿/红/琥珀仅用于成功/失败/阻塞。
4. **本地工具 ≠ Agent 角色**：两个一级入口，各自回答“有什么环境”“谁来做”。
5. **主管统一入口 + 受控定向指令**：单 Agent 不强制主管；定向指令显示目标、投递状态与主管同步。
6. **安全边界暂停**：`等待暂停 → 已暂停` 两段；`正在请求停止 → 已停止/状态待确认` 两段；重试生成新 Run。
7. **不虚构成功**：创建≠执行；提交≠完成；部分成果必须分组标注；状态不明显示“待确认/无法检测”。

## 6. 已知限制

- 原型为静态前端 Mock：**无持久化**（刷新复位，设置 → 关于 → 重置演示）、无真实执行、无真实日志流、无后端。
- 关系图为静态可视化（不支持拖拽连线）；无真实 OS 通知；审批“任务内授权”按规范保持禁用并标注“规划中”。
- 导出与复制为真实的浏览器行为，但内容为演示数据；不读取真实文件系统。
- 截图证据使用画布导出图：本机集成浏览器面板仅 400px 宽且存在截图拼接伪影，原型视觉请在本机 1280×800 窗口复核。
- 900×650 下“设置 / 帮助与反馈”需滚动侧栏到达（符合可滚动可达，非首屏可见）；侧栏固定展开，不再收窄为图标条。
- 企业多租户管理、真实窗口边框截图、录屏、多语言不在本轮范围。

## 9. 前端工程（根目录 frontend，Mock 阶段）

原型已工程化为 Vue 3 + TypeScript 前端，**视觉基线仍是本目录原型**，未重新设计。

```text
frontend/
├── src/{router,components/{ui,layout},features,services/{contracts,mock,adapters},stores,lib,styles,types}
├── tests/{unit,e2e}
├── docs/{00-prototype-audit,01-architecture,02-design-tokens,03-service-contracts,04-visual-diff,05-handoff,06-test-report}.md
└── package.json · vite.config.ts · vitest.config.ts · playwright.config.ts
```

- 启动：`cd frontend && pnpm install && pnpm dev` → http://localhost:5273
- 页面：16 个路由（含 `/states`）；侧栏固定展开、关系图使用 Vue Flow。
- 接口：10 个 Service 契约（Agent / Tool / Team / Task / Approval / Run / Workspace / Settings / Notification / Event），全部带 JSDoc（用途、时机、参数、返回、错误、Mock 行为、Rust 职责）。
- Mock：`services/mock` 为唯一事实来源；页面不直接写死数据。
- 检查结果：生产构建与 9 个单元测试通过；Playwright E2E 因缺少 Chromium 浏览器未能运行，详见 `frontend/docs/06-test-report.md`。
