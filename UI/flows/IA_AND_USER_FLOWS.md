# VocaMesh · 信息架构与用户流程（v1.2）

> 画布版本：`UI/VocaMesh.pen` → `06 · 信息架构与导航地图`。低保真：`05 · 低保真线框 S01–S16`。
> 原型版本：`UI/prototype/index.html`（左侧导航全部可点击，返回工作台一步）。

## 1. 信息架构：单层分组导航

```text
VocaMesh                                    [折叠]
工作
  工作台          S02   创建任务并查看正在进行的工作（默认入口）
  全部任务        S06   查找、筛选、打开与切换全部任务
  待审批          S11   集中处理 Agent 等待你决定的请求（计数徽标）
  历史记录        S12   追溯 Run、关键操作与部分成果
Agent 与协作
  Agent 角色      S08   决定执行环境扮演什么职责
  本地工具        S07   这台电脑上有哪些可运行的执行环境
  Agent 团队      S09   谁向谁汇报（主管与下属）
  工作空间        S10   任务能读写的本地目录与访问边界
应用
  通知            S15   需要关注的事件（跳转审批或任务）
────────────────────────────
  设置            S13
  帮助与反馈      S16
```

### 1.1 导航规则

| 规则 | 落地方式 |
|---|---|
| 文字优先 | 默认展开 240px，图标只作辅助；不提供“仅图标”默认态 |
| 一次点击到达 | 每个入口直接进入目标页，无二级常驻目录 |
| 选中表达 | 中性白/深灰背景 + 轻阴影 + 600 字重；无彩色竖线、无绿色高亮 |
| 焦点独立 | 2px 高对比轮廓，与选中可同时存在 |
| 计数 | 只出现在“待审批 / 通知”；中性颜色 + 文字标签 |
| 展开策略 | **始终展开 240px，不提供折叠/展开控件**；窄窗也保持完整文字标签（至少 240px） |
| 底部固定 | `设置 / 帮助与反馈` 固定在底部，列表独立滚动 |
| 空状态入口 | 空状态按钮直接跳到对应页面（如“去本地工具”） |

### 1.2 5 秒辨识 & 两步可达

- **5 秒**：不读说明即可定位“创建任务（工作台输入区）”“配置 CLI（本地工具）”“创建 Agent（Agent 角色）”“处理审批（待审批）”。
- **两步**：任意一级入口 ≤ 2 步到达；从任意页返回工作台 1 步（侧栏或按钮）。
- **消歧**：本地工具 = 可运行环境；Agent 角色 = 职责；Agent 团队 = 汇报关系；工作空间 = 目录边界。帮助页有对照表。

## 3. 用户流程（F01–F11）

### F01 首次启动与工具发现
`欢迎页 → 自动扫描 → 状态列表（可用 / 认证待验证 / 未安装 / 无法检测）→ 跳过或进入工作台`
- 不强制创建组织、不要求 API Key；无可用工具时仍可浏览。
- 仅在可靠检测时显示“可用”，其余显示“认证待验证 / 无法检测”。
- 支持手动指定路径与重新扫描；显示路径与版本，不读取凭据。

### F02 创建 Agent 角色
`Agent 角色 → 新建 Agent → 名称 / 职责 / 执行工具 → 保存（状态：未就绪）→ 完成任务再执行`
- 一个工具可支撑多个角色；保存 ≠ 已运行；改动只影响新任务/新 Run。

### F03 团队与关系图（可操作）
`Agent 团队 → 关系图（默认）或树形 → 拖动/缩放查看 → 节点 + 添加下属 → 编辑信息 → 添加直属上级 → 关系检查（自我管理 / 间接环）→ 保存`

- **关系图是可操作视图**（不只是展示）：
  - 拖动空白处平移，滚轮或 − / + 缩放（45%–160%），「适应视图」「自动整理」；
  - 拖动节点可手动排布位置，位置在本会话内保留；
  - 节点悬停显示 `+`（添加下属）与 `⋯`（编辑信息 / 添加下属 / 添加直属上级 / 设为团队主管 / 移除此成员）；
  - 「+ 添加 Agent」在画布内直接创建角色并挂到选中节点之下（同时创建 Agent 角色，状态未就绪）；
  - 任何会造成自我管理或间接环的上级设置会被阻止，并在提示中给出环路径。
- 视图切换只有一个实例，位于团队卡片标题行（不在页面顶部重复）；树形视图保留为结构化编辑（改上级、看表格）；组织关系与任务依赖仍是两套语义。

### F04 创建任务
`工作台输入 → 确认工作空间 + 执行方式（快速执行 / 选择团队 / 自定义）→ 创建 → 排队中 → 环境检查通过 → 执行中`
- 快速执行不启动主管；选择团队由主管协调；自定义展开子任务/依赖/授权。
- 提交后明确区分“已创建任务”“排队中”“已开始执行”。

### F05 任务详情（核心）
`顶部状态与动作 → 摘要计数 → 执行流程 → 主管对话 → 输入区（按需 Inspector）`
- 流程与对话在同一连续内容区，提供“流程聚焦 / 对话聚焦”轻量切换。
- 子任务点击 → Inspector 定位；审批卡内联出现，同时顶部保留提示。

### F06 定向指令
`选择下属 Agent → 输入指令 → 影响预览（若改变计划）→ 提交 → 排队/待投递 → 已送达（运行时确认）→ 执行中（若可确认）→ 已应用 / 未应用 / 投递失败`
- 默认记录“已同步主管”（结构化事件）；CLI 不支持增量输入时显示“等待安全投递点”。

### F07 审批
`请求出现（任务内卡 + 全局计数）→ 查看内容/作用域/风险 → 拒绝 / 仅此一次允许 → 记录写入`
- 默认不允许；超时不批准；拒绝后不重试；单份记录（任务与待审批页共享）。
- 仅在具备撤销能力时提供更宽授权（原型标为“规划中”）。

### F08 暂停 / 停止 / 继续 / 重试

| 操作 | 过程状态 | 终态 | 禁止 |
|---|---|---|---|
| 暂停 | `等待暂停：已停止派发，当前步骤仍在运行` | `已暂停`（全部到达安全边界） | 提前宣称已暂停 |
| 停止 | `正在请求停止` | `已停止 / 停止失败 / 状态待确认` | 把“请求发出”当“已停止” |
| 继续 | 权限、依赖、输入版本检查 | 恢复调度 | 声称无法恢复的进程“原地继续” |
| 重试 | 创建新 Run | 新 Run 运行，旧 Run 保留 | 覆盖旧日志；状态不明时自动重试 |

失败分支：无关子任务继续；依赖失败节点阻塞；主管进入“需要处理”；用户选择 `仅重试失败部分` / `跳过并生成标注完整性的部分成果` / `停止整个任务`。

### F09 并行任务
- 工作台聚合 `执行中 / 等待处理 / 排队中 / 已完成 / 失败` 数量。
- 任务切换通过工作台/全部任务/最近任务进入，不使用无限 Tab。
- 关闭窗口 vs 退出应用分别说明（设置 → 窗口与退出；原型给出限制说明）。
- 资源不足显示“排队等待资源”及原因；目录冲突给出提醒与隔离建议。

### F10 无法执行 / 失败 / 部分成果
- 场景可单独进入：未安装 / 未登录 / 路径无效 / 能力不支持；状态无法获取 / 断开 / 超时；审批阻塞 / 拒绝；主管或下属失败；用户停止后保留成果。
- 部分成果必须按 `已完成 / 跳过 / 失败` 分组并标注缺失范围，不得暗示整体成功。

### F11 新手通过左导航完成首次操作
`工作台 → 本地工具（查看状态）→ Agent 角色（新建）→ 工作台（创建任务）→ 待审批（处理示例）→ 历史记录（追溯）`
- 每步左侧只有一个直白入口；空状态提供文本链接，不要求理解术语。

## 4. 状态语言契约（展示层）

**任务**：草稿 · 排队中 · 执行中 · 等待审批 · 等待暂停 · 已暂停 · 需要处理 · 正在停止 · 已停止 · 部分完成 · 已完成 · 失败 · 状态待确认

**子任务**：未开始 · 等待依赖 · 准备执行 · 执行中 · 等待审批 · 成功 · 失败 · 已阻塞 · 已跳过 · 已取消 · 状态未知

**工具**：可用 · 待验证 · 需登录 · 未安装 · 不兼容 · 无法检测

**Run**：待启动 · 启动中 · 执行中 · 等待输入 · 停止请求中 · 已结束 · 异常退出 · 状态未知

**审批**：待处理 · 允许一次 · 任务内授权（需撤销能力）· 已拒绝 · 已撤销 · 已过期

> 状态与颜色的映射见 `design-system/components.md` §4 与 `handoff/UX_STATE_MATRIX.md`。

## 5. 桌面布局适配

| 档位 | 侧栏 | 检查器 | 关键约束 |
|---|---|---|---|
| 1600×900 | 240 | 可固定 360 | 正文保留 ≥900px |
| 1280×800（基准） | 240 | 内联 360（按需） | 任务详情正文 ≥990px |
| 1024×720 | 240（固定展开） | 覆盖抽屉 320 | 表格与筛选可换行，不横向溢出 |
| 900×650 | 240（固定展开） | 覆盖抽屉 320 | 主操作始终可达，设置/帮助经滚动可达 |

- 侧栏不提供折叠按钮：品牌区只有 Mark 与 VocaMesh / by Vocafect，避免误触与“图标猜功能”。
- macOS：交通灯左上，侧栏通高（顶部留 38px 安全区），标题栏中置标题。
- Windows：右侧最小化/最大化/关闭（44×32），左侧标题与拖动区分离。
- 滚动边界：侧栏、内容、检查器三者独立。

## 6. 边界与限制

- 原型不访问真实 CLI、文件系统、网络或凭据；所有路径与 Run 均为虚构。
- 关闭窗口后继续执行、多任务文件隔离、增量指令投递能力取决于未来 Rust Core / 适配器，界面以“待确认 / 规划中 / 等待安全投递点”诚实呈现。
