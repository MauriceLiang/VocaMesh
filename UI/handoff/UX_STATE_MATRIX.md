## 4. Run 状态

`待启动 · 启动中 · 执行中 · 等待输入 · 停止请求中 · 已结束 · 异常退出 · 状态未知`

历史记录列表中：执行中=中性、已完成=绿、异常退出=红、部分完成=琥珀、已停止=中性、状态未知=中性+help。
重试必须显示“旧 Run 保留 / 新 Run 编号”。

## 5. 审批状态

| 状态 | 视觉 | 结果 | 可撤销 |
|---|---|---|---|
| 待处理 | 琥珀 | 无 | — |
| 允许一次 | 绿（记录） | 执行继续 | 仅在其作用域内 |
| 任务内授权 | 绿（规划中） | 需可靠撤销能力才提供 | 是 |
| 已拒绝 | 红 | 步骤不执行，不重试 | — |
| 已过期 | 中性 | 不自动批准 | — |
| 已撤销 | 中性 | 停止授权 | — |
| 无法确定 | 中性 + help | 显示待确认 | — |

## 6. 操作反馈契约

| 用户动作 | 立即反馈 | 最终反馈 | 禁止 |
|---|---|---|---|
| 创建任务 | 团队/单 Agent：“任务已创建 · 排队中”；自定义：“待配置占位任务已创建” | 团队/单 Agent 由 Mock 状态迁移进入执行；自定义模式保持 `draft`，不参与调度 | 直接把创建当执行成功；将 Mock 状态描述为真实执行 |
| 暂停 | “已停止派发新工作” | “已暂停（到达安全边界）” | 提前说已暂停 |
| 停止 | “正在请求停止” | “已停止 / 停止失败 / 状态待确认” | 请求=已停止 |
| 重试 | “正在创建新 Run” | “新 Run #xxxx 已启动” | 覆盖旧记录 |
| 审批 | “决定已记录” | 任务状态变化 + 记录条目 | 默认同意 / 超时批准 |
| 定向指令 | “排队待投递” | “已送达 → 已应用 / 未应用 / 等待投递点” | 未确认即写“已应用” |
| 工具检测 | “正在请求状态” | “已验证可用 / 仍无法确认” | 假定登录成功 |

## 7. 颜色语义（唯一映射）

| 语义 | Light | Dark | 使用范围 |
|---|---|---|---|
| 成功 | `#187447` | `#76D2A0` | 仅：已完成 / 成功 / 可用 / 已允许 |
| 失败 | `#B13A43` | `#FF9299` | 仅：执行失败 / 异常退出 / 不兼容 / 已拒绝 |
| 阻塞 | `#8B5A00` | `#EBC16B` | 仅：等待审批 / 已阻塞 / 需登录 / 部分完成 / 冲突风险 |
| 中性 | `#666666` | `#B5B5B5` | 待配置 / 运行中 / 排队 / 暂停 / 跳过 / 未知 |

不得用于：选中态、品牌强调、普通加载、装饰。
