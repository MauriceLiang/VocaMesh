# VocaMesh 交互原型（Mock / 零依赖）

**打开方式**：双击 `index.html` 即可（file:// 运行，无需安装、无需构建、无需服务器）。
推荐窗口 **1280×800** 或更宽；1024×720 / 900×650 会自动收窄侧栏并把检查器改为抽屉。

**直接打开某个页面（便于逐项验收）**：在地址后加 hash，例如
`index.html#/dashboard`、`#/task`、`#/approvals`、`#/tools`、`#/settings`、`#/states`。
可用值：`welcome dashboard tasks task tools roles teams workspaces approvals history settings states notifications help`。

```text
prototype/
├── index.html     入口（无外部依赖、无网络请求）
├── styles.css     设计令牌 + 组件样式（明/暗、舒适/紧凑）+ 菜单/弹层
├── data.js        全部模拟数据（任务、Run、审批、工具、角色、团队、日志、命令面板）
├── ui.js          图标与渲染 helper（badge / button / 状态文案映射）
├── screens1.js    S01、S02 工作台、S04 任务详情、S05 检查器、S06 全部任务
├── screens2.js    S07–S16 + 菜单 / 11 类弹窗 / 命令面板 / Toast
└── app.js         状态机、动作表、菜单与弹窗系统、剪贴板、文件导出、快捷键
```

## 1. 现在「全部可点」——没有一个按钮是死的

原型内每一个 `data-action` 都绑定到真实行为（已用脚本遍历 14 个页面 / 15 个弹窗的所有交互元素校验：**0 个未绑定**，**200+ 次点击 0 异常**）。

### 1.1 全局

| 控件 | 行为 |
|---|---|
| 侧栏 11 个入口 | 路由到对应页面（`aria-current` 同步） |
| 折叠侧栏 | 240 ↔ 60px 图标条 + Tooltip |
| 顶栏搜索 / `⌘K` | 命令面板：输入过滤、`↑↓` 选择、`Enter` 执行 |
| 顶栏月亮/太阳 | 亮暗主题即时切换 |
| 顶栏 `?` | 快捷键说明弹窗 |
| 通知铃铛 / `M` 头像 | 进入通知 / 占位（不可点→已改为通知） |
| `Esc` | 依次关闭菜单 → 命令面板 → 弹窗 → 检查器 |
| 页脚 设置 / 帮助与反馈 | 路由 + 设置分区 |

### 1.2 工作台 S02 / 全部任务 S06

- **模板库**：3 个模板弹窗 → 选中后把描述与执行方式写回输入框并聚焦。
- **工作空间选择**：菜单列出 4 个工作空间（带路径、当前项打勾）。
- **执行方式**：快速执行 / 选择团队 / 自定义，右侧提示随之变化。
- **创建任务**：直接创建或经 S03 弹窗创建；先 `排队中`，1.4s 后 `执行中`；附件会写进任务首条消息。
- **指标卡**：点击 → 跳到「全部任务」并套用对应状态筛选。
- **任务行**：点击进入详情；行尾 `⋯` 打开菜单（打开 / 暂停或继续 / 复制 Run 编号 / 复制摘要 / 归档）。
- **筛选**：状态、工作空间、执行者、时间四个菜单真实过滤表格；「清除筛选」复位。
- **搜索**：即时过滤任务名 / 工作空间 / Run 编号，`Enter` 打开第一行。

### 1.3 任务详情 S04 / 检查器 S05

- **暂停 → 继续 → 停止**：`等待暂停 → 已暂停`、`正在请求停止 → 已停止`；状态与横幅文案实时变化。
- **重试失败部分**：生成新 Run 编号，旧编号保留（提示中给出对照）。
- **跳过并生成部分成果**：失败/阻塞项变「已跳过」，任务变「部分完成」。
- **任务 `⋯` 菜单**：复制任务链接、导出执行摘要（真实下载 .md）、跳到历史、归档。
- **@ 目标切换**：切到「分析师」后发送 → 定向指令四段投递（排队 → 已送达 → 等待安全投递点 → 已应用）并带主管同步说明。
- **附件**：选择 3 个模拟文件 → 显示可移除的附件 chip。
- **检查器 4 Tab**：活动（子任务事件）、日志（搜索/级别筛选/自动滚动/复制/加载更早）、成果（文件预览弹窗）、信息（查看日志 / 在时间线定位 → 高亮对应流程节点）。
- **审批卡**：允许 / 拒绝 → 写入记录、改变任务状态、主管补充一条消息。

### 1.4 待审批 S11 / 历史 S12

- 队列筛选（待处理 / 已处理）、点击切换详情。
- **允许 / 拒绝**：状态与记录同步；已处理项不再显示批准入口。
- 历史：类型/结果/时间筛选、加载更多（真实追加行）、行菜单（查看任务 / 复制 Run / 导出日志 / 在新 Run 重试）。
- **导出记录（CSV）** 与 **导出部分成果（CSV）**：通过 Blob 真实下载到本机（内容为演示数据）。

### 1.5 关系图（S09 默认视图）

- **平移 / 缩放**：拖动空白平移；滚轮以指针为中心缩放（45%–160%）；工具条 − / + / 适应视图 / 自动整理。
- **拖动节点**：直接拖动卡片排布，连线实时跟随；位置保存在本次会话内。
- **节点操作**：悬停或选中节点显示 `+` 与 `⋯`；`+` 直接以该节点为上级新建 Agent；`⋯` 提供编辑信息、添加下属、添加直属上级、设为团队主管、移除此成员。
- **画布内建角色**：`+ 添加 Agent` 会同时创建 Agent 角色与团队成员，状态按所选工具推导（未就绪 / 需登录 / 可用）。
- **关系校验**：自我管理、间接环一律阻止并提示环路径；主管不能被直接移除（需先指定新主管）。
- **切回树形**：视图切换只保留**一处**，位于团队卡片标题行（紧邻「编辑关系 / 添加成员」），树形与关系图共用同一份数据；页面顶部不再放第二个切换。

### 1.6 本地工具 S07 / 角色 S08 / 工作空间 S10

- 工具：`测试认证` / `验证登录`（状态迁移 + 提示）、`设为默认`（写入状态并显示徽标）、`查看配置`、`手动指定路径`（保存后变「无法检测」）、`安装与登录指南`（可复制命令）、`错误详情`（可复制）。
- 角色：切换执行工具（角色状态随之变为可用/需登录）、权限开关、展开角色指令与执行参数、保存、删除（二次确认弹窗）。
- 团队：新建团队、编辑关系（名称/主管/默认空间）、**添加成员**（重复成员 → 阻止；把主管加为下属 → 自我管理提示）、成员 `⋯`（设为主管 / 移除）。
- 工作空间：新建（名称 + 路径）、编辑读写边界（保存生效）、查看完整路径（可复制）、排队解决目录冲突。

### 1.6 设置 S13 / 通知 S15 / 帮助 S16 / 状态合集 S14

- 设置：主题、密度、动效、灰度、平台外框、退出行为、并发、自动重试、日志保留、通知偏好、重置演示、快捷键。
- 通知：全部/未读/审批筛选、逐条查看、逐条移除、全部标为已读。
- 帮助：搜索框过滤条目、9 篇文章（含术语、暂停语义、审批、CLI 安装、部分成果、快捷键）、反馈提交（记录在会话内并回显计数）。
- 状态合集：9 张卡片的按钮全部跳到对应页面或触发对应动作。

## 2. 布局与对齐规则（逐页测量）

| 项 | 规则 |
|---|---|
| 页面内边距 | 26px（紧凑 20，≤1024 窗 18） |
| 标题基线 | 所有页面 `.page-title` 左边缘 x=266、顶边 y=110；`.page-head` 高 46 |
| 标题块与操作 | 右侧按钮组底边与标题块底边对齐 |
| 两列页 | 左列与右列顶边 y 相等（列表列 **320** / 右侧栏 **340**） |
| 导航列 | 设置 200、帮助 260 |
| 面板 | 圆角 8；`.panel` 内边距 14；详情面板 16；列表卡 12；表格单元格 12 |
| 纵向节奏 | 页面块间距 12；列表卡间距 8；表格行高等高 |
| 任务详情 | 上方滚动区 + 底部固定输入区（不重叠审批卡） |

> 验证方式：脚本对 12 个页面读取 `getBoundingClientRect()`，标题 x/y、两列顶边、列宽均一致；`scrollWidth == innerWidth`（无横向溢出）。

## 4. 模拟边界（仍然是 Mock）

| 项目 | 说明 |
|---|---|
| 执行 | 由定时器驱动状态迁移，不代表真实耗时/成功率 |
| 文件 | 导出用 Blob 真实下载演示内容；不读取真实文件系统 |
| 剪贴板 | 优先 `navigator.clipboard`，file:// 下回退 `execCommand` |
| 持久化 | 无（刷新回到首次启动；设置 → 关于 → 重置演示） |
| 关系图 | 静态节点视图，不支持拖拽连线 |
| 审批“任务内授权” | 明确标注“规划中”并禁用（需撤销能力） |
| 通知系统项 | 无真实 OS 通知 |

> 所有路径、Run 编号、来源、日志均为虚构；不调用真实 CLI、不访问网络、不收集凭据。

### 3.1 Loading 指示（本项目已修正）

“执行中 / 处理中 / 扫描中”统一使用**虚线圆环持续旋转**：`stroke-dasharray: 5 7.4`、`stroke-width: 2.4`、1.1s 线性无限循环、`transform-origin: center`。

- 不能用“实心弧线整体自转”（视觉上像圆圈本身在转，易误读）。
- `prefers-reduced-motion: reduce` 或设置中开启“减少动态效果”时，圆环静止显示（仍保留形状与文字）。
- 实现：`ui.js` → `UI.icon("loader")` 输出带 `ic-spin` 类的虚线圆；`styles.css` → `.ic-spin`。

## 5. 建议验收路径（≈4 分钟）

1. 首次启动 → `重新扫描` → `开始使用 VocaMesh`。
2. 工作台 `模板库` 选一个模板 → `创建任务`（观察 排队 → 执行）。
3. 任务详情：`暂停` → 等 2s → `继续` → `停止`。
4. 待审批：`允许` 一条，再 `拒绝` 另一条，回到任务看横幅与流程变化。
5. 打开失败任务「整理供应商合同条款对比」→ `仅重试失败部分` / `跳过并生成部分成果`。
6. 检查器：日志搜索 `warn`、复制、加载更早、成果预览。
7. 任务输入框点 `@ 主管` → 切到分析师 → 发送，观察投递四段状态。
8. 全部任务：用四个筛选菜单过滤；行尾 `⋯` 暂停/复制 Run/归档。
9. 历史记录：筛选 → `导出记录(CSV)` → 确认浏览器下载。
10. 本地工具：`测试认证` Codex → 状态变可用；`手动指定路径`；`查看配置`。
11. 团队：`添加成员` 选「研究协调员」→ 出现阻止提示；成员 `⋯` 移除。
12. 设置：亮/暗、紧凑、灰度、Windows 外框；`⌘K` 面板 → 跳到「历史记录」。
