# VocaMesh · 组件规范（v1.2）

> 组件源：`UI/VocaMesh.pen` → `01 · 系统组件库（可复用源）`（Badge / Button / Input / Select / Segmented / Switch / NavItem 为可复用组件，页面中以实例引用）。
> 状态板：`02 · 设计令牌与排版`、`03 · 组件状态板`。原型实现：`UI/prototype/styles.css` + `ui.js`。
> 每个交互组件必须提供：`Default / Hover / Focus-visible / Pressed / Disabled`，适用的额外提供 `Selected / Loading / Error`。

## 3. 输入控件

| 状态 | 表现 |
|---|---|
| Default | `bg.surface` + `border.default` |
| Hover | 边界 `border.strong` |
| Focus | 2px `focus.outline`（offset −1），边界透明 |
| Filled | 文本 `text.primary` |
| Disabled | `#F5F5F5` 底 + `#A8A8A8` 字，附原因说明 |
| Error | `status.failure.bg` 底 + 2px 失败色边 + 图标 + 下方错误文案 |

Select 右侧固定 chevron；Combobox 支持键盘上下键与 Enter（原型中为占位）。

## 4. 状态徽标（跨页面唯一语义）

| 语义 | 颜色 | 图标 | 文案示例 | 何时使用 |
|---|---|---|---|---|
| Success | 绿 | check | 已完成 / 成功 / 可用 / 已允许 | 结果已被确认 |
| Failure | 红 | x | 执行失败 / 异常退出 / 不兼容 / 已拒绝 | 明确错误或终结 |
| Blocked | 琥珀 | alert-triangle | 等待审批 / 已阻塞 / 需登录 / 部分完成 | 因依赖、授权或资源停滞 |
| Neutral | 灰 | dot / loader / hourglass | 排队中 / 执行中 / 已暂停 / 已跳过 | 正常过程 |
| Unknown | 灰 | help-circle | 状态待确认 / 无法检测 | 无法确认，不得假定成功 |

**禁止**：把“已提交请求”显示为成功；把“等待暂停”显示为已暂停；把“部分完成”显示为成功；同一状态在不同页面使用不同颜色。

## 5. 侧栏（Sidebar）

- 结构：品牌区（Mark + VocaMesh + by Vocafect + 折叠按钮）→ 分组 `工作 / Agent 与协作 / 应用` → 弹性空白 → 固定底部 `设置 / 帮助与反馈`。
- 项：高 34，圆角 6，图标 15 + 完整中文标签 + 可选计数徽标。
- 状态：Hover = 55% surface 混合；Selected = `bg.selected` + `shadow-selected` + 600 字重；Focus-visible = 2px 轮廓。
- **不提供折叠/展开**：侧栏始终 240px 展开，不显示折叠按钮，也不使用仅图标模式；窄窗下仍保留完整文字标签。
- 计数徽标：中性白底 + 细边；仅风险状态才使用语义色（本设计统一使用中性，避免色彩泛滥）。
- 溢出：列表独立滚动；`设置 / 帮助与反馈` 固定在底部；900×650 下全部入口可达（滚动）。
- 反例：折叠成图标条、第二层常驻导航、仅图标默认态、绿色选中、把“本地工具”和“Agent 角色”合并。

## 6. 任务执行流（Flow Node）

- 结构：状态图标（18×18）+ 标题 + 执行者/结果（元信息）+ 状态徽标 + chevron。
- 行高 44–52，节点间 1px 分隔（不用虚线边框装饰）。
- 状态色：成功=绿勾；失败=红叉；等待审批/已阻塞=琥珀底 + 琥珀图标；执行中=旋转 loader；等待依赖=hourglass。
- 点击 → 打开 Inspector 并定位该子任务（活动/日志/成果/信息）。

## 7. 审批卡（Approval Card）

必须包含 6 个要素：**哪个 Agent、属于哪个任务、要做什么（命令/路径）、授权作用域、风险原因、可选操作**。

- 操作顺序：`拒绝`（次按钮）在左，`仅此一次允许`（主按钮）在右；`本次任务内允许` 仅在有可靠撤销能力时出现，原型中显示为禁用并标注“规划中”。
- 默认不选中任何决定；超时 → `已过期`（灰），不会自动批准。
- 结果状态：待处理 / 允许一次 / 已拒绝 / 已过期 / 已撤销 / 无法确定；全部写入记录时间线。
- 任务内审批卡与 `待审批` 页面指向同一记录（单份数据），避免重复决策。

## 8. 事件与消息

- 三种视觉层级：① 主管/用户消息（气泡，圆角 8，`bg.surface` / `bg.subtle`）；② 结构化事件卡（审批、里程碑，带状态徽标）；③ 原始日志（仅 Inspector 日志 Tab，等宽字体）。
- 消息永不伪装成执行日志；日志永不进入对话流正文。
- 定向指令卡显示：目标 Agent、指令正文、影响分析、投递状态、主管知悉标记。

## 9. Inspector（检查器）

- 四个 Tab：`活动 / 日志 / 成果 / 信息`；日志 Tab 含搜索、级别筛选、自动滚动开关、复制、“加载更早”、行数与“演示数据”标注。
- 默认关闭；选中子任务时打开并定位；窄窗（≤1080px）为覆盖式抽屉（右，宽 320，`shadow-overlay`）。
- 滚动边界独立，不抢占正文宽度。

## 10. LogViewer

- 等宽 10.5px，四列：时间 / 级别 / 角色 / 消息；WARN 行使用琥珀浅底 + 琥珀级别字。
- 初次只展示 14 行（共 231），底部提供“加载更早”，避免一次渲染大量行。
- 自动滚动可暂停，避免打断屏幕阅读器；日志区不参与 `aria-live`。

## 11. Loading 指示器（执行中 / 处理中）

- **形状**：虚线圆环（`stroke-dasharray: 5 7.4`，`stroke-width: 2`，半径 8.6/24），不是实心弧线。
- **动画**：整个圆环绕中心旋转（`1.1s linear infinite`），虚线在旋转中形成“流动”感。
- **禁止**：实心弧线自转（看起来像圆圈本身在转动）、闪烁、发光。
- **尺寸**：11px（badge 内）· 13px（按钮/指标卡）· 15px（工具栏），不得低于 11px。
- **减少动效**：`prefers-reduced-motion: reduce` 或设置项开启时静止显示（保留形状），状态仍由文字 + 徽标表达。
- **配套文案**：`执行中 / 处理中 / 扫描中`，不得只用动画表达状态。

## 12. EmptyState / Skeleton / ProgressSummary

- EmptyState：标题 + 一句解释 + 1–2 个明确下一步按钮（禁用插图代替行动）。
- Skeleton：仅用于加载面板，不使用闪烁动画（减少动态效果下静态）。
- ProgressSummary：只给出计数（已完成 / 执行中 / 阻塞 / 未开始 / 总数），**不显示虚构百分比**。

## 13. Tooltip / Toast / Menu / Dialog

- Tooltip：延迟 300ms，仅文本，最大 240px，跟随 focus。
- Toast：右下角，最长 4.2s；成功/失败/阻塞使用语义图标；不使用“已完成”措辞描述尚未确认的动作。
- Menu：7–8 圆角，行高 30，支持 Esc 关闭与方向键（原型为占位）。
- Dialog：宽度 ≤760，内容决定高度，焦点进入首个可交互元素；`Esc` 关闭；关闭后焦点回到触发按钮。

## 14. 键盘与无障碍约定

| 操作 | 快捷键（原型/建议） |
|---|---|
| 命令面板 | `⌘K` / `Ctrl+K` |
| 关闭弹层/抽屉 | `Esc` |
| 发送任务消息 | `Enter`（`Shift+Enter` 换行） |
| 列表激活 | `Tab` 聚焦 → `Enter` 打开 |
| 侧栏折叠 | 品牌区按钮（可聚焦） |

- 所有图标按钮必须有 `aria-label`；导航使用 `aria-current="page"`；计数徽标以文本形式出现在可访问名称中。
- 焦点顺序与视觉顺序一致；抽屉/对话框关闭后焦点回到触发元素。
- 状态徽标使用“颜色 + 图标 + 文字”，灰度模式下仍可区分（见 T24）。


## 14. 关系图（Org Chart）

| 项 | 规范 |
|---|---|
| 画布 | 点阵网格背景（16px 间距，`border.default` 1px 点），`bg.inset` 底色 |
| 节点 | 196 × 54 卡片：头像 26、名称 12/600、职责 10/400 muted、右侧 6px 状态点（绿=可用、琥珀=需登录、灰=未就绪）；`radius 8`、`shadow-selected` |
| 根节点 | 头像反相（黑底白字），副标题前缀「主管 · 」 |
| 选中 | 2px `text.primary` 边框 + 内边距 −1 补偿，保持外框尺寸不变 |
| 连线 | 父节点底边中点 → 子节点顶边中点，三次贝塞尔；1.4px `border.strong`，命中选中节点时 2px `text.primary` |
| 节点操作 | 悬停/选中时在底边中点显示 `+`（添加下属）与 `⋯`（菜单），22px 圆形按钮 |
| 工具条 | 左侧操作提示；右侧 − / 百分比 / + 、适应视图、自动整理、`+ 添加 Agent`（主按钮） |
| 交互 | 拖动空白=平移；滚轮=以指针为中心缩放（45%–160%）；拖动节点=移动并即时重连；点击节点=选中（键盘 Enter/Space 同效） |
| 菜单项 | 编辑 Agent 信息 · 添加下属 · 添加直属上级… · 设为团队主管 · 从此团队移除（危险项红字） |
| 约束 | 不允许自我管理；不允许间接环（阻断并给出路径）；主管不可直接移除（需先指定新主管） |
| 无障碍 | 节点 `role="button"` + `aria-label="名称，职责"`，Tab 可达，Enter 选中 |
| 空状态 | 团队无成员时在画布中央给出「添加第一个 Agent」按钮，而非空白网格 |
