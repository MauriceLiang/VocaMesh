# VocaMesh · 设计令牌（v1.2）

> 适用：UX/UI 设计交付与 Mock 原型。**唯一事实来源**：`UI/VocaMesh.pen`（画布变量，主题轴 `mode` = light / dark）+ `UI/design-system/tokens.json`（机器可读）+ `UI/prototype/styles.css`（`--*` 自定义属性）。三者数值一致。

## 1. 原则

1. **黑白灰承担全部静态界面**：背景、面板、按钮、导航、表格、对话区不使用品牌彩色。
2. **只有三种语义状态色**：成功（绿）、失败（红）、阻塞/待审批（琥珀）。运行中、排队、已暂停、状态待确认一律使用中性灰。
3. **选中态三重线索**：中性浅背景 + 低强度阴影 + 字重变化；不以颜色表达选中。
4. **聚焦态独立**：键盘 `focus-visible` 使用 2px 高对比轮廓 + 2px offset，不复用阴影。
5. **状态永不只靠颜色**：颜色 + 图标 + 文字 + 下一步动作，四项齐全。

### 2.1 对比度核算（WCAG 2.2 AA 参考）

| 组合 | Light | Dark | 结论 |
|---|---|---|---|
| 成功色 / 主面板 | 5.79:1 | 9.63:1 | AA |
| 失败色 / 主面板 | 5.91:1 | 8.22:1 | AA |
| 阻塞色 / 主面板 | 5.90:1 | 10.36:1 | AA |
| 成功色 / 成功浅底 | ≈5.3:1 | ≈8.4:1 | AA |
| 失败色 / 失败浅底 | ≈5.4:1 | ≈7.6:1 | AA |
| 阻塞色 / 阻塞浅底 | ≈5.2:1 | ≈9.0:1 | AA |
| 正文主色 / 主面板 | 17.6:1 | 15.2:1 | AAA |
| 次级文本 / 主面板 | 7.1:1 | 8.9:1 | AAA |
| muted 文本 / 主面板 | 5.3:1 | 7.1:1 | AA |

> 计算基于 sRGB 相对亮度；半透明背景与图片底需在实际渲染上重新核算。灰度模式（设置 → 灰度预览）用于验证状态不只依赖色相。

## 3. 排版

- 字体：系统栈（`-apple-system / Segoe UI Variable / PingFang SC / Microsoft YaHei / Inter`），日志使用 `SF Mono / Consolas`。
- 桌面正文 **13px**，辅助 12px，元信息 10.5px（不再更小），页面标题 22–25px，区块标题 16px。
- 行高：正文 1.6，紧凑列表 1.4，日志 1.45；标题 letter-spacing −0.2 ~ −0.5。
- 数字计数使用等宽数字（表格、Run 编号、日志、路径一律等宽）。

## 4. 间距、圆角、尺寸

| 项 | 值 |
|---|---|
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32 |
| 页面内边距 | 26（舒适）· 20（紧凑）· 18（≤1024 窄窗） |
| 页面纵向间距 | 12（所有页面统一） |
| **两列列宽** | 列表列 **320** · 右侧栏/详情栏 **340** · 导航列 **200** |
| 面板内边距 | 14（`.panel`）· 详情面板 16 · 列表卡 12 · 表格单元格 12 |
| 圆角 | badge 4 · 控件 6 · 卡片 8 · 对话框/窗口 10 · **不使用胶囊按钮** |
| 行高 | 34（舒适）/ 30（紧凑） |
| 控件高 | 32（舒适）/ 28（紧凑） |
| 侧栏 | 240 展开 / 200 中窗 / 60 折叠 |
| 检查器 | 360；≤1080px 时改为覆盖式抽屉 |
| 任务输入区 | 固定于内容区底部（滚动区之上，不遵盖审批卡） |

**对齐规则（已逐页测量）**

1. 全部页面标题左边缘 x=266、顶边 y=110（1280×800，侧栏 240 + 描边 1 + 内边距 26 − 1）。
2. 页面标题块高度统一 46px，右侧操作按钮与标题块底边对齐（差值 0）。
3. 两列页面的左列与右列顶边 y 完全一致（170 / 212 / 248 / 379 依内容而定，但左右相等）。
4. 卡片圆角均为 8，表格首列/末列内边距 12 与卡片内边距对齐。
5. 画布高保真：所有内容区 padding 26（窄窗变体 18）；标准页面纵向间距 16，任务详情采用 12 的密集间距（内容密度差异已在设计决策中说明）。

## 5. 层级与状态

```css
--shadow-selected: 0 1px 3px rgb(0 0 0 / 10%), 0 4px 10px rgb(0 0 0 / 5%);
--shadow-selected-dark: 0 1px 4px rgb(0 0 0 / 48%), 0 3px 12px rgb(0 0 0 / 25%);
--shadow-overlay: 0 8px 24px rgb(0 0 0 / 12%);
--shadow-dialog: 0 16px 48px rgb(0 0 0 / 18%);
```

| 状态 | 处理 | 备注 |
|---|---|---|
| Default | 无阴影或虚线以内极轻 | 不显得已激活 |
| Hover | 背景变化（`bg.subtle` 或 55% surface 混合） | 不新增投影 |
| Selected | `bg.selected` + `shadow-selected` + 600 字重 | 侧栏与列表一致；暗色可加 1px 中性边界 |
| Focus-visible | 2px `focus.outline` + offset 2 | 与选中同时出现时仍清晰可辨 |
| Pressed | 背景加深一档 | 无缩放/弹跳 |
| Disabled | 文字/边框降饱和 + 明确原因文案 | 不用颜色单独解释 |
| Floating | `shadow-overlay` / `shadow-dialog` | 仅菜单、抽屉、对话框 |

## 6. 动效

120ms（hover/切换）· 160ms（抽屉/面板）· 上限 180ms。不使用发光、弹跳、视差。`prefers-reduced-motion: reduce` 或设置内“减少动态效果”时全部降为 0ms。

## 7. 主题与密度

- 主题：`跟随系统 / 亮色 / 暗色`；只切换令牌，不改变布局、字号与状态色语义。
- 密度：`舒适 / 紧凑`，仅影响行高、控件高、页面内边距与正文字号（13 → 12.5）。
- 平台：macOS 使用左上交通灯 + 全高侧栏；Windows 使用右侧最小化/最大化/关闭（44×32 热区），标题栏左侧留出拖动区。
