# Roadmap

## 已交付基础

- Vue + Tauri 2 桌面壳、Rust workspace/Core/Agent 分层和稳定工具 IPC。
- Codex、Claude Code、OpenCode 安装路径与固定版本发现。
- 非敏感手动路径和默认值设置；未知认证状态不作为可用工具。

## 下一阶段：单 Agent 受控执行闭环

- 用户明确授权的工作目录；目录授权与任务输入确认。
- 固定 Provider 启动参数、受控进程管理和权限策略。
- 实时输出、背压/截断、取消、超时、退出状态及 Run 生命周期。
- 日志脱敏与审计，错误恢复和重启后的任务状态语义。
- 先用 Mock 验证任务 UI 与 IPC，再以用户触发的只读任务完成真实 CLI 集成。

本阶段不表示真实 Agent 执行、任务调度或任务日志已接入。
